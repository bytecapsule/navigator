# 个人导航

一个单文件的个人浏览器起始页：把常用服务按分类收在一起，支持站内过滤、分类筛选和搜索引擎跳转。

## 特点

- **站内搜索**：按服务名称、描述、标签实时过滤，关键词为空时显示全部
- **分类筛选**：左侧栏显示分类与条目数，点击只看该分类
- **最近访问**：自动记录最近点开的 12 个服务，只保存在本机 localStorage，不上传
- **搜索跳转**：输入关键词后可直接用 Bing 或 Google 搜索
- **键盘操作**：按 `/` 聚焦搜索框，按 `Esc` 清空并退出
- **明暗切换**：默认 Light；右上角的月亮/太阳按钮切换 Light/Dark，选择保存在本机 localStorage，下次打开自动恢复
- **单文件零依赖**：样式、脚本、数据都在 `navigator.html` 内，不请求外部字体、图片或 CDN，用 `file://` 打开即可
- **响应式**：桌面为侧栏 + 卡片网格；窄屏下分类变为顶部横向按钮条，更窄时卡片收为两列。保留键盘焦点样式，并遵循 `prefers-reduced-motion`
- **线性图标**：分类图标为内联 SVG（放大镜、芯片、文档、终端、用户、指南针），不依赖 emoji 或图标库

| AI | 17 | 对话、研究，以及语音、音乐、视频生成 |
| 办公 | 11 | 文档、笔记、邮箱、图表 |
| 开发 | 7 | 代码托管、云计算、GPU 平台 |

当前共 56 个服务。分类内按类型顺序展示，目前没有统一的国内/国外排序规则。

## 使用

1. 打开 `navigator.html`（双击或拖进浏览器即可，不需要服务器）
2. 把它设为浏览器主页，或固定为标签页
3. 点击卡片会在新标签页打开服务，同时该服务进入「最近访问」

如果希望在其他设备访问，可以把仓库发布到 GitHub Pages 等静态托管，无需构建步骤。

## 自定义

所有站点数据都在 `navigator.html` 里的 `<script type="application/json" id="navigator-data">` 中，改完刷新页面即可生效。

- **新增服务**：在 `services` 里加一条，`id` 需唯一，`category` 必须是 `categories` 中已有的 `id`
- **分类**：`categories` 中的 `id` 同时用于筛选、锚点和图标映射，`name`、`description` 会直接展示；`icon` 字段目前保留但不再渲染
- **主题**：浅色变量在 `:root`，深色变量在 `html[data-theme=dark]`，改 `--page`、`--brand` 等即可调整配色；选择存放在 `navigator-theme`
- **注意**：最近访问保存的是服务 `id`，修改已有 `id` 会让对应的历史记录失效

## 已知限制

- 「最近访问」只存在当前浏览器，换浏览器或清缓存会丢失；禁用 localStorage 时不记录
- 搜索只匹配名称、描述、标签，不匹配分类名
- 没有收藏、置顶功能
- 排序为手工维护，不保证国内服务优先
- 主题默认 Light，不跟随系统主题；选择保存在本机 localStorage，清除浏览器数据或禁用存储后回到 Light

## 性能

- 零外部请求，图标全部为内联 SVG
- 导航和最近访问只在初始化或数据变化时渲染
- 搜索只更新会显示的分区，切换卡片可见性而不重建列表；连续输入会在 80ms 内合并
- 明暗切换只改变根级 CSS 变量，不重建 DOM

当前 56 项的规模仍是一次构建全部卡片；如果服务数量增加到数百项，应改为按需渲染或虚拟列表。

## 开发

无构建、无依赖。改动后直接刷新浏览器即可。若想用本地服务器预览：

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000/navigator.html
```
